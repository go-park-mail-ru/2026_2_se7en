## ДЗ 2: работа с БД

Подключён PostgreSQL через `pgxpool`. Схема, ограничения, индексы и тестовые данные находятся в миграциях `migrations/001`–`005`; миграции запускаются через `tern` с конфигурацией `migrations/tern.conf`. Бэкенд получает строку подключения из `DATABASE_URL`, проверяет соединение при старте и в `GET /api/v1/health`.

Применение миграций: `tern migrate -c migrations/tern.conf -m migrations`. Для запуска бэкенда нужно задать `DATABASE_URL` для той же базы и выполнить `go run .`

В `repository` реализованы операции с пользователями, профилями, сессиями, контактами и чатами: создание и поиск пользователя, изменение профиля, управление контактами, диалогами и группами, получение участников и истории сообщений. Регистрация сохраняет пользователя, профиль и сессию в одной транзакции. Сейчас через HTTP доступны регистрация, вход, выход, свой профиль и список чатов.
