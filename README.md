# 2026_2_se7en

Репозиторий бэкенда команды se7en

## Структура

- `main.go` — точка входа: подключение к БД, роутер, запуск сервера
- `config.go` — загрузка настроек из переменных окружения
- `handlers/` — HTTP-обработчики (API): auth, user, chat, message
- `storage/` — работа с БД: SQL-запросы, по файлу на сущность
- `models/` — структуры данных (маппинг таблиц БД)
- `middleware/` — auth-middleware, читает сессию из cookie
- `utils/` — сессии, пароли
- `migrations/` — SQL-миграции
